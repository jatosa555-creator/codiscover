# Security and responsible use

## Data handling

- Use synthetic, redacted, or authorized data for demonstrations.
- Do not provide credentials, secrets, personal identifiers, regulated records, or confidential organizational documents unless the selected environment is approved for them.
- Treat user statements, AI inferences, and unknowns as different provenance classes.

## Human accountability

CoDiscover must identify a human owner for consequential decisions and tests. It must not recommend autonomous production execution when decisions are high-impact, irreversible, safety-critical, legally sensitive, or based on weak evidence.

## Reporting

For this prototype, report security or privacy concerns to the repository owner through a private channel rather than a public issue containing sensitive details.
