# CoDiscover Privacy Notice

Last updated: 18 July 2026

CoDiscover's current ChatGPT App server processes the challenge, desired outcome, work context, and candidate ideas supplied to a tool call only to produce that response. Version 0.1 does not create user accounts, persist tool inputs or outputs, sell personal data, or send content to an additional model or third-party data service.

The hosting provider and ChatGPT may process technical request data under their own policies. Users should not provide sensitive, confidential, regulated, or unauthorized information during this prototype unless an approved deployment and data agreement explicitly permit it.

CoDiscover outputs are advisory. They may contain errors or incomplete assumptions. A human owner must review outputs before consequential use.

Questions or privacy concerns can be raised through the public repository's GitHub Issues page.
