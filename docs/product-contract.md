# CoDiscover Product Contract v0.1

## Product definition

CoDiscover is a Human–AI Use Case Discovery and Work Design Plugin.

## Promise

Help any value-creating work system start from a real challenge, discover and prioritize opportunities, and design a responsible Human–AI use case through a decision-ready experiment with explicit evidence and human accountability.

## Core journey

`Discover → Decide → Design → Test → Learn`

The hackathon frontstage compresses this to:

`Challenge → Use Case → MTUC`

## Primary user

A person helping self or others turn a real work challenge into an AI use case. This includes individual contributors, team or project leads, AI champions, facilitators, consultants, transformation partners, executives, and policy designers.

## Supported contexts

- solo human–agent system;
- work cell or small team;
- function or unit;
- organization;
- networked organization or ecosystem.

## Product requirements represented in v0.1

| Requirement | Behavior or artifact |
|---|---|
| P-001 | Plugin and Skill identify CoDiscover as Human–AI use-case discovery and work design. |
| P-002 | Skill analyzes a value-creating work system rather than headcount. |
| P-003 | Workflow adapts questions and depth to the user's context. |
| V-001 | Four separate value dimensions; no default total score. |
| M-001 | Quick Discover produces framing, candidates, trade-offs, risk, and next step. |
| J-002 | Ask only material questions, label assumptions, and stop when sufficient. |
| R-001 | Use the lightest sufficient method and expose why deeper design is needed. |
| I-001 | Facts, assumptions, and unknowns remain separate. |
| H-001 | MTUC requires an accountable human owner and checkpoints. |
| G-001 | Deterministic Critical Gate check covers responsibility conditions. |
| O-001 | Context Snapshot, candidate cards, and MTUC form the core output. |
| O-002 | Minimum means the least resource use that still tests the highest-risk assumption. |

## Prototype boundary

In scope:

- Quick Find, Quick Compare, and Quick Sharpen;
- conditional Deep Design;
- Markdown and structured JSON output;
- local Plugin installation;
- schema and critical-gate validation;
- synthetic demonstration cases.

Out of scope:

- production execution;
- autonomous final decisions;
- live enterprise integrations;
- full multi-agent orchestration;
- unverified ROI or environmental claims;
- redistribution of internal or licensed evidence libraries.
